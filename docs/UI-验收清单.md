**布局基准**（`node tools/graph-bench.mjs`，Node v24.22，固定夹具、每档 3 次取中位数；阈值 1k<120ms、3k<300ms、5k<600ms）：最近一次运行 1k 8.81ms / 3k 28.04ms / 5k 48.19ms（同为中位数，机器负载不同会在约 9–11 / 28–35 / 48–56ms 波动，均远低于阈值）；位置数 = 节点数 − 1，根节点无位置，两次布局校验和一致。对应测试 `ui/tests/graph-perf.test.mjs` 5/5 通过。

### 6.3 未验与已知限制

| 项 | 状态 | 说明 |
|---|---|---|
| 浏览器 FPS / 内存 | ⏳ 未验 | 无浏览器控制；`layoutGraph` 基准只覆盖布局计算，Canvas 绘制、DPR、GPU 与内存未测 |
| 触屏 pinch | ⏳ 未验 | 代码有 `touchstart/touchmove/touchend`（`passive:false`，双指缩放），真机手感与命中未验；单指拖动是转相机，不是拖节点 |
| 1,200 节点上限 | 已知限制 | 超过上限只保留权重较高的 1,200 个节点（结构节点优先）；提示「已显示 X / Y（上限 1,200）」，没有分页/按类型下钻 |
| 静态布局 | 已知限制 | `layoutGraph` 是哈希锚点的确定性静态布局，不是力导向；刷新/换筛选后节点重排（tween），不支持手工摆位 |
| DPR 上限 1.5 | 已知限制 | 高分屏（DPR 2–3）按 1.5 渲染换取帧率，文字/光晕略糊 |
| 标签预算 | 已知限制 | 每帧最多 40 个标签，碰撞避让会跳过重叠标签；较长标签截断到 26 字 |
| 读屏节点列表 | 已知限制 | 只列前 300 个非 root 节点 |
| 布局主题 | 已知限制 | 0.18.2 起删掉 7 个布局主题，只保留默认星图外观；背景深浅与配色仍可从抽屉切 |
